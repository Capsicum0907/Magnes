# 設定

[English](config.md) | 日本語

サーバー設定です。ゲームフォルダの `config/magnes-server.toml` に置かれます。
ワールド内の `serverconfig/magnes-server.toml` に写しを置くと、そのワールドではそちらが優先されます。
どの値も使うそのティックに読みます。

| キー | 既定値 | 範囲 | 働き |
|---|---|---|---|
| `enabled` | `true` | | 全体のスイッチ。オフにすると、誰が何を持っていても何も引き寄せません。 |
| `magnet.needed` | `true` | | 磁石を持っている必要があるか。オフにすると全プレイヤーが常に磁力を持ち、アイテムは飾りになります。 |
| `magnet.mustBeHeld` | `false` | | 磁石がインベントリのどこにあっても効くのではなく、手（または Curios のスロット）にあるときだけ効くようにするか。 |
| `pull.radius` | `6.0` | 1.0〜32.0 | 磁石の届く距離（ブロック数）。プレイヤーの当たり判定の箱から外側へ測ります。 |
| `pull.mode` | `TAKEN` | `TAKEN`、`DRAWN` | `TAKEN` はインベントリへ直接入れます。`DRAWN` はプレイヤーの方へ飛ばし、通常どおり拾わせます。見栄えは良いものの、取りこぼすことがあります。 |
| `pull.drawnSpeed` | `0.35` | 0.05〜2.0 | `DRAWN` での速さ（ブロック毎ティック）。`TAKEN` では使いません。 |
| `pull.includesExperience` | `true` | | アイテムに加えて経験値オーブも引き寄せるか。オーブは、歩いて触れたときと同じ速さで吸収されます。 |
| `cost.tickInterval` | `1` | 1〜40 | 走査の間隔（ティック数）。`1` で毎ティック。上げると `DRAWN` の動きが粗くなる代わりに、走査の負荷が減ります。 |
