# Magnes

[English](README.md) | 日本語

アイテムと経験値のほうから寄ってきます。

*Magnes* はラテン語で磁石、そして磁石を切り出す磁鉄鉱のことです。

> **状態：公開済み、1.0.0。** 実際のクライアントで動作を確認済み。ゲームテスト9件が画面なしの実行で通ります。

## 対象

| | |
|---|---|
| Minecraft | 1.21.1 |
| ローダー | NeoForge 21.1.248 |
| Java | 21 |

大型の工業系 Mod が留まったのが 1.21.1 なので、この Mod が役に立つのもそこです。

## 使い方

**磁石を作って持ち歩きます。** 鉄インゴット4個とレッドストーンブロック1個を、磁石の形そのままに並べます。

```
I I
I I
 R
```

インベントリのどこにあっても効きます。手に持たなくてよいことがこのアイテムの要点です。右クリックでオンとオフを切り替えます。
オンのときはカラー、オフのときはグレーで描かれます。

[Curios](https://www.curseforge.com/minecraft/mc-mods/curios) が入っていれば charm スロットに身に着けることもでき、
身に着けた磁石は手に持っているものとして数えます。Curios は任意です。

**磁石が無ければ何も起きません。** これをわざわざ書くのは、初めて遊んだときにこの Mod が壊れているように見えたからです。
「アイテムがプレイヤーに寄ってくる」と名乗り、`enabled` という全体のスイッチまで用意しておきながら、
誰にも知らされていないアイテムを待って黙っていました。全員に磁力がある、という読み方にしたいなら、
`[magnet]` の `needed = false` を設定すれば、それが本当になります。

## 設計

プレイヤーの近くに落ちたアイテムと経験値オーブは、歩いて触れるのを待たず、プレイヤーのほうへ移動します。

**引き寄せはサーバーで行い、他のどこでも行いません。** 落ちているアイテムの位置はワールドの状態で、
ワールドの状態を決めるのはサーバーだけです。クライアントが独自にアイテムを動かすと、誰が何を拾ったかでサーバーと食い違います。

**他人のものは取りません。** アイテムのエンティティは、拾えるまでの待ち時間と、プレイヤーの死亡直後には短い間だけ持ち主を持っています。
どちらも尊重します。部屋の向こうから他人の落とした持ち物を引き寄せる磁石は、便利道具ではなく嫌がらせの道具になるからです。

引き寄せ方は2通りあり、得るものが違います。

- インベントリへ直接入れる：確実で、地味
- プレイヤーへ向けて速度を与え、通常どおり拾わせる：見栄えは良いが、取りこぼすことがある

どちらにするかは設定で選び、ここでは決めません。

届く距離、オンとオフ、何を引き寄せるかも設定です。この Mod は、コードに数値を書けば真っ先に変えたくなる類のものです。
これらを設定にできるのは、どれも使うそのティックに読むからです。道具の採掘範囲は、アイテム登録時にデータコンポーネントへ
焼き込まれるので、こうはいきません。

**拾う処理を自前では書いていません。** アイテムも経験値オーブも、`playerTouch` を通じて自分をプレイヤーに渡す方法を既に持っています。
そこでは、拾えるまでの待ち時間、アイテムの持ち主、効果音、進捗、他の Mod が聞いている拾得イベント、
オーブなら経験値より先に修繕を適用すること、が扱われます。それを呼ぶかどうかが、この Mod が拾い方に口を出すか出さないかの違いです。

知っておくとよい帰結が1つあります。オーブは歩いて触れたときと同じ速さ、つまり2ティックに1個で吸収されます。
磁石は経験値を集めはしますが、急がせはしません。

磁石は手の中だけでなく、インベントリのどこにあっても効き、右クリックでオンとオフを切り替えます。
オフの状態はアイテムに記録します。一度も触っていない磁石はそのまま効くので、作りたての磁石は状態を何も持ちません。

詳しいこと（磁石を探す順番、Curios まわりの守り、テスト）は [docs/how-it-works.ja.md](docs/how-it-works.ja.md) にあります。
設定の一覧は [docs/config.ja.md](docs/config.ja.md) にあります。

## ビルド

```
run.bat                   # コンパイルして開発用クライアントを起動（ダブルクリックでも可）
gradlew build             # jar を作る
gradlew runGameTestServer # 全ゲームテストを画面なしで実行して終了
gradlew runData           # モデル・レシピ・言語・テスト用構造物を生成し直す
python tools/make_textures.py   # アイテムの絵を生成し直す
```

`JAVA_HOME` が JDK 21 を指しているか、`java` が `PATH` 上にある必要があります。

## 未決事項

- 届く距離を設定で変えられる磁石1種類で良いのか、それともプレイヤーが強化していくものにすべきか。
- `DRAWN` の狙いを目ではなく足元にすべきか。今は目を狙っており、アイテムには合っていますが、オーブには少し不自然です。
- 引き寄せる対象で絞り込むか。許可リストは種類の違う設定がもう1つ増えることになるので、入れるなら理由が要ります。
